# Install
clone
````
git clone https://github.com/manuiunam/oemof_examples.git
````
````
cd oemof-energy-system
````
use conda
````
conda env create -n oemof-examples -f environment.yml
OR
conda env update -f environment.yml --prune
````
````
conda activate oemof-examplesw
````
